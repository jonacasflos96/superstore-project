# superstore-project - Data Science ToolBox
This is the final project for superstore

## Dataset
This dataset has been downloaded from Kaggle. Dataset containing Information related to Sales, Profits and other interesting facts of a Superstore giant. Available in: 

https://www.kaggle.com/datasets/vivek468/superstore-dataset-final?utm_source


## Questions to adress
Q1: Where is the problem?
Which sub-categories bring strong sales but weak profit, and how much of their loss is linked to discounts?

Q2: What should Superstore do about it?
From which discount level does profit turn negative, and when and where should Superstore test smaller discounts, taking seasonality and whole orders (baskets) into account?
